# Database

Modelo relacional, scripts SQL y documentación de base de datos.

Para setear la base se ejecuta los documentos .sql en orden de arriba para bajo, primero los que estan dentro de la carpeta scripts y luego los de la carpeta seeds.

Orden
1. database/scripts/config1_database.sql
2. database/scripts/config2_tables.sql
3. database/scripts/config3_indexes.sql
4. database/seed/roles.sql
5. database/seed/data.sql
